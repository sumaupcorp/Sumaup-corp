# features/licenses — Licencias / membresías del SaaS ERP

Gestión de licencias/membresías del SaaS ERP por tenant: alta, baja, renovación y estado.
Define qué negocio (tenant) tiene qué plan. Operación cross-tenant. El backend valida cada
operación; la UI refleja y dispara vía API. Ver skill `backoffice-licensing`.
