Fuente de marca: Manrope (SIL Open Font License 1.1).

Incluida: Manrope-variable.ttf
  - Fuente VARIABLE oficial de Google Fonts (eje wght 200-800).
  - Origen: https://github.com/google/fonts/tree/main/ofl/manrope
  - Declarada en pubspec.yaml (family: Manrope). Flutter mapea
    fontWeight (w400-w700) al eje variable, no hacen falta TTF estaticos.

No versionar el .ttf si el repo excluye binarios; en ese caso volver a
descargar con el comando de arriba.
