# components/layout — Estructura visual del dashboard

Componentes de armazón: topbar, sidebar, contenedor de página, breadcrumbs y la cáscara del
área autenticada. El sidebar se construye desde `enabledModules` (ver `sidebar/README.md`).
Lenguaje visual heredado de la landing: azul/celeste/blanco, Manrope/Sora, sin modo oscuro.
