# components/dashboard — Bloques del panel principal

Tarjetas de KPI, resúmenes, secciones de inicio y widgets del panel. Componen datos de varios
módulos en la vista general. Usan `charts/` para gráficos (Recharts) y `tables/` para listados.
Siempre con estados de carga / error / vacío. Sin emojis, fondo blanco.
