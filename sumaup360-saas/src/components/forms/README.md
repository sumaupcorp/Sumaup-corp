# components/forms — Formularios reutilizables

Campos, validación y formularios compartidos (alta/edición de entidades del ERP). Preferir
react-hook-form + zod y componentes de shadcn/ui. Textos en español real, sin emojis. Los
botones de envío se gatean por `permissions` (UX); la autorización real la valida el backend.
