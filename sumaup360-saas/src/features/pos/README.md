# features/pos — Caja / POS

Punto de venta y manejo de caja por sucursal: carrito, cobro, apertura/cierre de caja. Módulo
core del ERP (`pos`), con variante `quick-pos` para bodega/minimarket. Aparece solo si está en
`enabledModules`. Acciones gateadas por permisos (`sale:create`, etc.); el backend valida.
