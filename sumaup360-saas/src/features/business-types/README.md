# features/business-types — Rubros y verticales

Catálogo de `businessType` y `vertical` para la configuración de la empresa. Determina los
módulos base y los catálogos propios del rubro. No clona el dashboard: solo configura el ERP
core. Ver `../../../docs/MODULE_SYSTEM.md` y `../../../docs/04-saas-erp-modules.md` (raíz).
